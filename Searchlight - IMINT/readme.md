# Overview

Searchlight - IMINT is an introductory Open Source Intelligence (OSINT) room focused on Image Intelligence (IMINT) and Geospatial Intelligence (GEOINT). The room demonstrates how publicly available information contained within images can be used to identify locations, landmarks, businesses, and other contextual information.

Throughout the room, I practiced visual analysis, reverse image searching, geolocation techniques, and using publicly available resources to answer investigation questions.

---

# Learning Objectives

- Develop an analytical mindset for image investigations.
- Extract contextual clues from photographs.
- Perform image-based geolocation.
- Use reverse image search effectively.
- Correlate information from multiple OSINT sources.
- Verify findings using maps and public records.

# Key Takeaways

- Different search engines may return different results.
- Google Maps and Street View are essential verification tools.
- Cross-validating information from multiple sources significantly improves accuracy.
